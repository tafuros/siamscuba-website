1TL;DR

הבסיס הטכני טוב יחסית: יש meta, OG, JSON-LD ל‑LocalBusiness ו-Courses, robots, sitemap, GTM, Consent Mode v2 — דברים שלרוב האתרים אין.

שלוש בעיות עיקריות פוגעות בנו היום:

  1. כל פוסט בלוג + כל דף קורס משתמשים ב‑title/description של דף הבית → גוגל לא מבין במה כל דף עוסק.
  2. אין hreflang למרות תמיכה ב-EN/HE/ES/FR → גוגל לא מציע גרסאות מתאימות לפי שפת המשתמש.
  3. hero-video.mp4 = 14.7MB נטען מיד → פוגע ב-LCP, אחד מארבעת ה-Core Web Vitals שגוגל מודד.

הסדר המומלץ לתיקון: B (מחקר keywords) → C (אודיט טכני מלא) → A (תיקונים בקוד עם נתונים).

פער #3 — אין hreflang למרות תמיכה ב-4 שפות

השפעה: משתמש מצרפת מחפש "padi koh tao" → גוגל לא יודע להציע לו את הגרסה הצרפתית. אנחנו "מבזבזים" 75% מהתוכן.
תוספת בלפחות hreflang per routeoption A: query param ?lang=he
// בכל route דרך <Helmet>:
+ <link rel="alternate" hrefLang="en" href={`https://siamscuba.com${path}`} />
+ <link rel="alternate" hrefLang="he" href={`https://siamscuba.com${path}?lang=he`} />
+ <link rel="alternate" hrefLang="es" href={`https://siamscuba.com${path}?lang=es`} />
+ <link rel="alternate" hrefLang="fr" href={`https://siamscuba.com${path}?lang=fr`} />
+ <link rel="alternate" hrefLang="x-default" href={`https://siamscuba.com${path}`} />
החלטה דרושה: ?lang=he (קל) או /he/path (טהור). מומלץ לעבור בהדרגה ל-/he/. נדון בשלב A.

פער #4 — sitemap.xml ידני; שוכחים לעדכן

scripts/generate-sitemap.ts (חדש)~30 שורות
+ import { writeFileSync } from "fs";
+ import { blogPosts } from "../src/data/blogPosts";
+ import { COURSE_TO_SLUG } from "../src/lib/courseSlugMap";

+ const SITE = "https://siamscuba.com";
+ const today = new Date().toISOString().split("T")[0];

+ const urls = [
+   { loc: "/", priority: 1.0, changefreq: "weekly" },
+   { loc: "/blog", priority: 0.8, changefreq: "weekly" },
+   { loc: "/fun-dive-booking", priority: 0.8, changefreq: "monthly" },
+   ...blogPosts.map(p => ({ loc: `/blog/${p.slug}`, priority: 0.9, changefreq: "monthly" })),
+   ...Object.values(COURSE_TO_SLUG).map(s => ({ loc: `/courses/${s}`, priority: 0.85, changefreq: "monthly" }))
+ ];

+ const xml = `<?xml version="1.0" encoding="UTF-8"?>
+ <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
+ ${urls.map(u => `<url><loc>${SITE}${u.loc}</loc><lastmod>${today}</lastmod><changefreq>${u.changefreq}</changefreq><priority>${u.priority}</priority></url>`).join("\n")}
+ </urlset>`;

+ writeFileSync("public/sitemap.xml", xml);

פער #5 — hero-video.mp4 = 14.7MB (פוגע ב-LCP)

השפעה: Core Web Vitals — LCP יעד < 2.5s. וידאו 14.7MB ב-3G/4G חלש = 5–10 שניות. גוגל מוריד דירוג.
אופציות לפעולהמומלץ: 2 + 4
1. Compress: ffmpeg -i hero-video.mp4 -vcodec h264 -crf 28 hero-720.mp4   // ~3-4MB
2. Replace with poster image first, lazy-load video on viewport
3. Move to Mux/Cloudflare Stream (HLS adaptive)
4. preload="none" + autoplay only on viewport intersect
5. Add <link rel="preload" as="image" href="/hero-poster.webp"> for instant LCP
